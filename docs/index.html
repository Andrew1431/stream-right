Built for watching, not broadcasting.

Streaming sites are made for one streamer and a crowd. This is made for four friends on a call who want to see each other's screens properly.

Nothing is recorded. Video goes from the streamer through Cloudflare's relay straight to viewers and is never stored on your server or Cloudflare's. If a room's owner turns on clips, viewers can save the last minute or two to their own device, and everyone in the room sees who's keeping a buffer and every clip that's saved.

Stream from OBS when the browser isn't enough.

Browsers throttle screen capture while your game has focus. OBS doesn't. Paste the room's server and token into OBS and your game goes out on your graphics card's encoder.

  • WHIP built into OBS 30+, nothing to install
  • Three simulcast layers on OBS 32+, so viewers still get Auto quality
  • Capture game audio only, keep voice chat off the stream
  • Each person gets their own token, revoked when the link rotates

Running in about ten minutes.

  1. Create a Realtime app

    In the Cloudflare dashboard, open Realtime → Serverless SFU and create an app. Keep its App ID and App Secret handy.

  2. Deploy

    Press Deploy to Cloudflare, paste the two Realtime values and a creator key you make up. Or clone the repo and run npm run deploy.

  3. Make a room, send the link

    Open your site, enter the creator key, name a room. Anyone with the invite link can join. Rotate it to lock everyone out.

You need a free Cloudflare account with a payment method on file; Cloudflare asks for one before turning on Realtime. Updating later is one click in your copy's Actions tab; see how.
